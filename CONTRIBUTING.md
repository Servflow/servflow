# Contributing

## The agreement

Every contribution needs the [Contributor License Agreement](CLA.md). The
whole of it is one page. In short: you keep your copyright, and you let
Servflow use what you contribute in every ServFlow product, including the
ones that are not open source.

To agree, put this line in the description of your first pull request:

    I have read the Contributor License Agreement in CLA.md and I agree to it.

A pull request from an account that has not agreed is not merged.

## Everything else

- Open an issue before a large change so the design is settled first.
- Keep a pull request to one change.
- Run `go build ./...`, `go vet ./...`, and `go test ./...` before you open it.
